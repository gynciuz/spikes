# spikes

Small, single-purpose automations. One folder per spike. Each folder carries a
`README.md` (what it does, how it runs, how to change it) and whatever data the
run reads. The record of runs is the scheduled task's run history on the account.

| Spike | What it does | Schedule |
|-------|--------------|----------|
| `newsletters/` | Marks newsletter subscriptions as read in Gmail (Google Apps Script) | daily, ~07:00 Europe/Vilnius |
